# Técnicas de Programação 
Repositório da disciplina técnicas de programação 
## Ementa 
- Conceitos de orientação a objetos: **Classes, Objeto,
Encapsulamento, Herança, Polimorfismo**.

- Princípios de padrões de projeto. Declaração de Classes e
Objetos. Classe Abstrata. Métodos. Sobrecarga de Métodos.

- Conceitos de Herança múltipla. Modificadores de acesso.
Construtores. Manipulação de Exceções.

- Conceitos e aplicações de arquitetura em Camadas. Uso de
Interface Gráfica.
